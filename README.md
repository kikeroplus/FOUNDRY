# FOUNDRY (Windows 版)

`ESP32/SkyLarkESP32` (foundry ブランチ) の 2 本目のゲーム「FOUNDRY」を Windows 11 に移したもの。
捨てられた工場を、六本脚の戦車が上へ登っていく縦シューティング。敵は工業機械に乗り移った AI。

`Foundry.exe` をダブルクリックで起動する。インストールは要らない (Windows に入っている .NET Framework 4 で動く)。
作りなおすときは `build.bat`。

## 画面

- ゲームの世界は ESP32 版と同じ 240x320 (当たり判定・速さ・敵の出る表・ボスの動きはそのまま)。
- 描くのは **3 倍の 720x960**。背景も 3 倍の細かさで作りなおした (床のむら、草、ひび、つた、光の筋、配管など)。
- 戦車・敵 10 種類・ボス 3 体・弾・爆発・部品は、3 倍の点で描きなおした (左上から光の当たる陰影とディザ、細い線、リベット、油圧の管など)。
- 文字は ESP32 版と同じ 6x8 の点の文字を拡大し、斜めのつなぎ目だけなめらかにしたもの。
- 窓の大きさは自由に変えられる (縦横比は保ち、余りは黒)。**F11 (または Alt+Enter) で全画面**。
- ゲームは 1 秒 30 回進めるが、描くのは 1 秒 60 回。動くもののあいだを補って描く。

## 操作

| 操作 | キーボード | ゲームパッド (XInput) | SkyLark Joystick ほか USB ゲームパッド |
|---|---|---|---|
| 歩く | 矢印 / WASD | 十字 / 左スティック | スティック / 十字 |
| 撃つ (押しっぱなしで連射) | Z / Space / J | A / X / RB / RT | SW1 (ボタン 1) |
| 爆弾 | X / K | B | SW2 (ボタン 2) |
| ゆっくり歩く | Shift | LB / LT | スティックの押し込み (ボタン 4) |
| スタート | Enter (Z でも始まる) | START | SW3 (ボタン 3) / SW1 |
| 一時停止 ⇔ 再開 | Esc / P | START | SW3 (ボタン 3) |
| 止めているときにやめる | Q | BACK | SW2 (ボタン 2) |
| 全画面 ⇔ 窓 | F11 / Alt+Enter | | |
| 音を消す ⇔ 出す | M | | |
| 音量 | - / + | | |

ネームエントリー: 上下で文字を選び、撃つボタンで次の文字へ、Backspace / X (パッドは B) で戻る。キーボードで名前を直接打って Enter でもよい。

ほかの窓に移ると、自動で一時停止する。

ESP32 版から変えたところ: 操作の案内の文字 (SW1 などをキーの名前に)、音量 (SW3 の段ではなく M と -/+)。
デモ中に SW3 長押しで選択画面へ戻る動きはない。

## 遊び方 (ESP32 版と同じ)

- 8 つの区画 (GRASS YARD → FOOTINGS → DUCTS → PIPE MAZE → PRESSES → SETTLING TANK → GREAT HALL → FURNACE) を登っていく。最後まで行くと 2 周目 (敵が強くなる)。
- ボス: PRESSES に STAMPER、SETTLING TANK に GANTRY、FURNACE に HEARTH。出ているあいだは流れが止まる。
- 機械を壊すと赤い核が飛び出し、近くの機械へ逃げて乗り移る (乗り移られた機械は強くなる)。撃ち落とすと 500 点。
- 爆弾: 砲塔の向きの先へ投げ、まわりの敵に傷を負わせて、生き残った機械をウイルスで 13 秒止める。
- 青い電池を拾うと弾が強くなる (4 段)。やられると 1 段下がる。
- 戦車は 3 機。4 万点と、そのあと 6 万点ごとに 1 機ふえる。

## 保存するもの

`%APPDATA%\Foundry\` に、ランキング (`scores.txt`)、前回の名前 (`name.txt`)、音量 (`sound.txt`)、窓の位置 (`window.txt`)。

## 作り

| ファイル | 中身 | ESP32 版 |
|---|---|---|
| `Program.cs` | 窓、入力 (キーボード・XInput・winmm のゲームパッド)、1 秒 30 回の進行と 60 回の描画、保存 | `main.cpp` |
| `Game.cs` | 遊びの流れ、戦車、弾、爆発、部品、文字と枠 | `game2.cpp` |
| `Enemies.cs` | 敵の出る表・動き・絵 | `game2_enemy.cpp` |
| `Boss.cs` | ボス 3 体 | `game2_boss.cpp` |
| `Background.cs` | 背景の 8 区画 (起動時に描いておく。0.2 秒ほど) | `g2bg.cpp` |
| `Gfx.cs` | 描く部品 (ESP32 版と同じ決まりの部品と、細かく描くための部品・陰影) | `g2draw.cpp` |
| `Text.cs` | 文字 | `gfx.cpp` の文字 |
| `Sound.cs` | 音の合成と waveOut | `sound.cpp` |

### 確かめる用

```
Foundry.exe --snap 出力の頭 フレーム...    指定したフレームの絵を PNG に (FOUNDRY_PLAY=1 で自動で遊ぶ、=2 で何もしない、FOUNDRY_SKIP=n で n 区画進める)
Foundry.exe --gallery 出力の頭             敵・弾・爆発とボス 3 体を並べた絵を PNG に
Foundry.exe --bench [フレーム数]           描く時間を測る
```
(`Foundry.exe` は窓のアプリなので、文字の出力を見るときは `/target:exe` で作ったものを使う)
